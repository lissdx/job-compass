# job-compass

**Status:** POC

## Pain

A job seeker loses track of their own search. They cannot say where each application stands, which ones went through whom, or what is waiting on a reply. Conversations with recruiters start from memory, and the memory is wrong.

## Goal

A tool the job seeker simply talks to. Ask it where any application stands, what went through whom, what is waiting on a reply — and get a straight answer from a record that is actually kept. Every application, every recruiter, every stage is stored and queryable, so the history is the tool's job and not the person's memory.

Later, possibly: automating the intake of openings and the submission of applications. Not now.

## Termination criteria

This project has no fixed end point. The first milestone is a working MVP; after that it keeps evolving as long as it is useful. It is the author's own initiative, and the author decides when it is finished.
